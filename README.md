# مِنهَاج | MINHAJ

منصة تعليمية لطلاب التوجيهي الفلسطيني. يضم المستودع الموقع الحالي المبني بـ HTML/CSS/JavaScript، وتطبيق Flutter جديدًا قيد النقل التدريجي إلى Android والويب، مع الحفاظ على مشروع Firebase وبياناته الحالية.

## تطبيق Flutter الجديد

المجلد: [`apps/minhaj_flutter/`](apps/minhaj_flutter/)

### ما يتضمنه أساس التطبيق
- واجهات عربية RTL متجاوبة لأندرويد والويب.
- تصفح الفروع والمواد والمصادر المنشورة مع فلاتر وترقيم صفحات محدود.
- حسابات الطلاب عبر Firebase Authentication وملفات مستخدمين في Firestore.
- البطاقات الشخصية والعامة: إنشاء وتعديل وحذف ومراجعة ومشاركة ونسخ مجموعة مشتركة.
- الاختبارات العامة والشخصية: إنشاء سؤال اختيار متعدد، التدريب والتصحيح المحلي، المشاركة والنسخ والحذف.
- إرسال مصادر مقترحة، متابعة حالتها، والإبلاغ عن مصادر معطوبة.
- التأسيس والحلول والوحدات الدراسية ودليل المدارس والمديريات.
- مساعد تعليمي يتصل بخدمة Cloudflare Worker الحالية، مع حدّ الاستخدام الموجود في قواعد Firestore.
- لوحة إدارة بحسب الأدوار: إدارة الفروع والمواد والتصنيفات والمصادر والتأسيس والحلول، مراجعة الاقتراحات والبلاغات، إدارة الحسابات الإدارية وسجل التدقيق.

> هذه إعادة بناء تدريجية. وجود الواجهة أو الكود لا يعني أن كل ميزة اجتازت اختبار إنتاج؛ يجب نجاح فحوص CI وتجارب Firebase الفعلية قبل الدمج أو تحويل الزيارات إلى التطبيق الجديد.

## تطوير Flutter

المتطلبات: Flutter stable وDart 3.4 أو أحدث.

داخل المستودع:
```sh
cd apps/minhaj_flutter
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

ويب التطوير يستخدم إعداد العميل العام الحالي لمشروع Firebase `minhaj-1be6f` افتراضيًا. لا تضع مفاتيح خدمة إدارية أو مفاتيح مزود AI في تطبيق Flutter.

### بناء أندرويد
سجّل تطبيق Android في مشروع Firebase نفسه بمعرّف الحزمة `com.karam.minhaj`، واستخدم قيم إعداد Android الخاصة به بدل إعادة استخدام `appId` الخاص بالويب. مثال:

```sh
flutter build apk --release \
  --dart-define=FIREBASE_API_KEY=YOUR_ANDROID_API_KEY \
  --dart-define=FIREBASE_APP_ID=YOUR_ANDROID_APP_ID \
  --dart-define=FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID \
  --dart-define=FIREBASE_PROJECT_ID=minhaj-1be6f
```

تفاصيل الإعداد موجودة في [README تطبيق Flutter](apps/minhaj_flutter/README.md).

## الحفاظ على المشروع الحالي

- التطبيق الجديد في `apps/minhaj_flutter/` معزول عن ملفات الموقع الحالي.
- لا تعدّل قواعد Firestore أو بيانات الإنتاج كجزء من إضافة الواجهات.
- صلاحيات الواجهة لتحسين التجربة فقط؛ الأمان الفعلي يجب أن يبقى في Firestore Rules.
- لا تستخدم استعلامات تحمل مجموعة `resources` كاملة. أبقِ النتائج محدودة وصفحاتها قابلة للتنقل.
- لا تُحوّل الزيارات إلى Flutter قبل التحقق من الفروع والمواد والمصادر والحسابات والأدوار ومشاركة المحتوى القديمة.
